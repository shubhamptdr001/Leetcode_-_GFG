# [Check if the number is Fibonacci](https://www.geeksforgeeks.org/problems/check-if-the-number-is-fibonacci4654/1?page=1&company=Adobe)
## Easy
Given an integer n, find if it is a Fibonacci Number.&nbsp;
Examples :
Input: n = 34
Output: true
Explanation: 34 is one of the numbers of the Fibonacci series.
Input: n = 41
Output: falseExplanation: 41 is not in the numbers of the Fibonacci series.
Constraints:1 ≤ n ≤ 104
