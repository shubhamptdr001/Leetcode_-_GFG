# [Longest Substring with Distinct Characters](https://www.geeksforgeeks.org/problems/longest-distinct-characters-in-string5848/1)
## Medium
Given a string s, find the length of the longest substring with all distinct characters.&nbsp;
Examples:
Input: s = "geeksforgeeks"
Output: 7
Explanation: "eksforg" is the longest substring with all distinct characters.

Input: s = "aaa"
Output: 1
Explanation: "a" is the longest substring with all distinct characters.
Input: s = "abcdefabcbb"
Output: 6
Explanation: The longest substring with all distinct characters is "abcdef", which has a length of 6.
