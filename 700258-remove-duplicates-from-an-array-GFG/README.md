# [Remove Duplicates from an array](https://www.geeksforgeeks.org/problems/remove-duplicates-in-small-prime-array/1)
## Easy
Given an array arr[] consisting of positive integers, return the array by removing all duplicate numbers.
Example:
Input: arr[] = [2, 2, 3, 3, 7, 5] Output: [2, 3, 7, 5]Explanation: After removing the duplicates 2 and 3 we get 2 3 7 5.
Input: arr[] = [1, 2, 3, 4, 5] Output: [1, 2, 3, 4, 5]Explanation: There doesn't exists any duplicate element.
Constraints:2≤&nbsp;arr.size()&nbsp;≤ 1061 ≤&nbsp;arr[i]&nbsp;≤ 109
