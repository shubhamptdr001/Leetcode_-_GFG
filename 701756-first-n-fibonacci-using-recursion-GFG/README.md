# [First n Fibonacci using Recursion](https://www.geeksforgeeks.org/problems/print-first-n-fibonacci-numbers1002/1)
## Easy
Given a number n, return an array containing the first n Fibonacci numbers.

The first two Fibonacci numbers are 0 and 1.&nbsp;
Each subsequent Fibonacci number is obtained by adding the previous two numbers.

Examples:
Input: n = 5
Output: [0, 1, 1, 2, 3]Explanation: The first 5 Fibonacci numbers are 0, 1, 1, 2, 3.

Input: n = 7
Output: [0, 1, 1, 2, 3, 5, 8]Explanation: The first 7 Fibonacci numbers are 0, 1, 1, 2, 3, 5, 8.
Input: n = 2Output: [0, 1]Explanation: The first 2 Fibonacci numbers are 0 and 1.
